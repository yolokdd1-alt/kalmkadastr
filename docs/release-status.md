Работа ведётся в feature/telegram-enquiries. Рабочий домен, контакты и Telegram пользователь подключит перед релизом. Публичный main остаётся демоверсией.

## Реализовано

- Обработчик Node.js для VPS: проверка полей, обязательного согласия, ограничений вложений, CORS и частоты обращений.
- Честные ответы о сбое доставки и частично отправленных вложениях. Секреты только в окружении VPS.
- Форма использует публичный адрес API из переменной сборки. Без адреса сохраняется явно обозначенный деморежим.
- Калькулятор передаёт параметры объекта в заявку, услуги передаются понятными названиями.
- Удалён код недоступных страниц проектов и кабинета.
- Добавлены уникальные title страниц, descriptions услуг, robots/noindex для тестовой версии, страница 404.
- Подготовлены systemd и пример Nginx для отдельного API-хоста. Конфигурация реального VPS не изменялась.
- Добавлены серверные тесты и CI для ветки разработки/PR.

## Ограничения

Нет постоянной очереди, автоматических повторов и антивируса вложений. При сетевом тайм-ауте результат может быть неоднозначным, интерфейс предупреждает пользователя. Лимит запросов в памяти процесса сбрасывается после перезапуска. Внешние соединения и доступ к VPS не настраивались.
