# КАЛМКАДАСТР

Интерактивный frontend-прототип сайта ООО «КАЛМКАДАСТР».

Сайт: https://yolokdd1-alt.github.io/kalmkadastr/

PDF-презентация: https://yolokdd1-alt.github.io/kalmkadastr/presentation.pdf

## Локальный запуск

```sh
npm ci
npm run dev
```

## GitHub Pages

Push в `main` запускает GitHub Actions: установка зависимостей, статическая сборка Next.js и публикация `out/`.

Сборка для вложенного пути:

```sh
NEXT_PUBLIC_BASE_PATH=/kalmkadastr npm run build
```

Без переменной сборка работает от корня домена. Изображения и шрифты используют соответствующий путь.

## Демонстрационные сценарии

Формы работают только в памяти браузера. Обращения и файлы не отправляются компании. Цены, реальные контакты и неподтверждённые достижения не вымышлены. Кейсы и кабинет содержат явно помеченные демонстрационные данные. Раздел с отдельной демонстрацией кадастровых работ удалён по запросу пользователя.

Логотип обрезан из предоставленного оригинального скриншота без перерисовки. Шрифт Manrope используется по SIL OFL (`public/fonts/OFL.txt`). Обобщённые контуры карты: Natural Earth, public domain.

Перед рабочим запуском нужны подтверждённые контакты и реквизиты, география работ, реальные материалы проектов и утверждённая политика обработки персональных данных.
